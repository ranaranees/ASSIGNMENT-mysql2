# ASSIGNMENT-mysql2
Employee Management System | MySQL

📌 Project Overview

This project focuses on creating and managing an Employee Management Database using MySQL and MySQL Workbench.

The project demonstrates practical applications of SQL, including database management, data manipulation, filtering, sorting, aggregate functions, grouping and table joins.

The objective is to understand how relational databases work and how SQL queries can be used to retrieve, analyse and manage employee-related information.

🛠️ Tools & Technologies

* Database: MySQL
* IDE: MySQL Workbench
* Language: SQL
* Operating System: Windows

🗂️ Database Structure

Database Name: employee

The database consists of three tables:

Table Name	Description
employees	Stores employee information
departments	Stores department details
location	Stores location information

1. Employees Table

Contains employee-related information, including:

* Employee ID
* Employee Name
* Gender
* Hire Date
* Designation
* Salary
* Department ID
* Location ID

2. Departments Table

Contains department information, including:

* Department ID
* Department Name

3. Location Table

Contains location-related information.

📊 Practical SQL Operations

Some of the practical operations performed include:

* Retrieving employee records based on specific conditions.
* Filtering employees based on salary and hiring dates.
* Updating employee designations.
* Sorting employees by department and salary.
* Retrieving employees hired in a particular year.
* Calculating total, average, highest and lowest salaries.
* Finding the number of employees in each department.
* Identifying departments based on average salary.
* Combining employee and department information using JOIN operations.

▶️ How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench.
3. Connect to your local MySQL instance.
4. Create or select the employee database.

6. Run the queries to view the results.
